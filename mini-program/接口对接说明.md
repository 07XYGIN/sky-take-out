# 小程序接口对接说明

本次只修改小程序前端。小程序接口完整路径统一为 /api/miniapp/...，后端由你实现。api.js 中的 /miniapp/... 会与基础地址 /api 拼接。
请求地址配置：utils/env.js，默认 http://localhost:8080/api。微信开发者工具可用 localhost；手机请改为电脑局域网 IP，正式发布使用 HTTPS 合法域名。
使用 HBuilderX 打开 mini-program，运行到微信开发者工具。H5 不支持真实微信登录和微信支付。

## 统一约定

- 成功返回 { code: 200, msg: '操作成功', data: ... }，兼容旧 code=1。
- 失败返回非成功 code 和 msg；登录失效用 401。
- 请求携带 Authorization: Bearer token，同时兼容旧 authentication 头。用户 token 与管理员 token 分开校验。
- 分页返回 { list: [], total: 0, pageNum: 1, pageSize: 10 }，兼容 records。
- 金额用 JSON 数字（元），长整型 ID 用字符串避免精度丢失。
- 日期使用 yyyy-MM-dd HH:mm:ss；前后端使用相同时区。
- 枚举、页大小、默认图标和省市区选项是前端配置，不是假业务数据。

## 登录和首页

| 方法和路径 | 请求 | data |
| --- | --- | --- |
| POST /miniapp/user/login | body: code（真实微信凭证） | token、user: { id, nickName, avatarUrl, gender, phone } |
| GET /miniapp/shop/status | 无，允许未登录访问 | 数字 1 营业、0 休息 |
| GET /miniapp/shop/getMerchantInfo | 无 | shopId、shopName、shopAddress、phone、description、deliveryFee、packPrice |
| GET /miniapp/category/list | 无 | 数组：id、name、type（1 菜品、2 套餐） |
| GET /miniapp/dish/list | categoryId | 数组：id、name、price、image、description、flavors，可选 monthlySales |
| GET /miniapp/setmeal/list | categoryId | 数组：id、name、price、image、description，可选 monthlySales |
| GET /miniapp/setmeal/dish/{id} | 套餐 ID | 数组：id、name、image、price、copies |

packPrice 是每件打包费，deliveryFee 是配送费。允许为 0，缺失时前端阻止下单，避免把未知费用当免费。用户手机号从 user.phone 读取，不使用商家电话。
未返回 monthlySales 时不显示销量。flavors 每项含 name 和 JSON 字符串 value，例如 { name: '辣度', value: '["不辣","微辣"]' }。图片提供完整 URL。

## 购物车和地址

| 方法和路径 | 参数/返回 |
| --- | --- |
| GET /miniapp/shoppingCart/list | 数组：id、dishId 或 setmealId、name、image、amount（单价）、number、dishFlavor |
| POST /miniapp/shoppingCart/add | body: dishId 或 setmealId、dishFlavor |
| POST /miniapp/shoppingCart/sub | 同上 |
| DELETE /miniapp/shoppingCart/clean | 清空当前用户购物车 |
| GET /miniapp/addressBook/list | 当前用户地址数组 |
| GET /miniapp/addressBook/default | 地址对象，无默认地址返回 data=null |
| GET /miniapp/addressBook/{id} | 地址对象 |
| POST /miniapp/addressBook | 新增地址 |
| PUT /miniapp/addressBook | 修改地址，含 id |
| DELETE /miniapp/addressBook | query: id |
| PUT /miniapp/addressBook/default | body: id |

地址字段：id、consignee、phone、sex、provinceCode/Name、cityCode/Name、districtCode/Name、detail、label、isDefault。后端按当前用户限制访问范围。

## 配送和下单

GET /miniapp/order/getEstimatedDeliveryTime?addressBookId=... 返回 data：

```json
{ "estimatedDeliveryTime": "2026-11-12 18:20:00", "today": ["18:30", "19:00"], "tomorrow": ["11:00", "11:30"] }
```

配送时段由后端根据营业时间和地址生成，不提供的时段返回空数组。立即派送使用 estimatedDeliveryTime，不在前端强行加一小时。
POST /miniapp/order/submit 接收 addressBookId、remark、estimatedDeliveryTime、deliveryStatus、tablewareStatus、tablewareNumber、packAmount、amount、shopId、deliveryFee、payMethod，返回至少 { id }。
后端从当前用户购物车校验商品状态并重新计价，前端金额仅供展示。

## 订单和支付

| 方法和路径 | 参数/用途 |
| --- | --- |
| GET /miniapp/order/historyOrders | page、pageSize、可选 status |
| GET /miniapp/order/queryOrdersCheckStatus | page、pageSize、payStatus（退款列表使用 2） |
| GET /miniapp/order/orderDetail/{id} | 订单详情 |
| PUT /miniapp/order/cancel/{id} | 用户取消，后端校验状态 |
| GET /miniapp/order/reminder/{id} | 催单 |
| POST /miniapp/order/repetition/{id} | 再来一单，填充购物车 |
| PUT /miniapp/order/payment | body: orderNumber、payMethod=1 |

订单字段：id、number、status、payStatus、orderTime、payDeadline、amount、packAmount、deliveryFee、estimatedDeliveryTime、consignee、phone、address、remark、tablewareNumber、tablewareStatus、shopName、shopTelephone、courierTelephone、orderDetailList。
orderDetailList 每项：name、image、amount（单价）、number、dishFlavor。
status：1 待付款、2 待接单、3 已接单、4 派送中、5 已完成、6 已取消、7 退款中；payStatus：0 未支付、1 已支付、2 退款中。
payDeadline 是服务端确定的付款截止时间；前端不再固定按 15 分钟计算，不会因为本地倒计时结束就自动取消订单，超时关闭由后端负责。
支付页按 ID 查询真实订单。支付接口返回 timeStamp、nonceStr、packageStr（或 package）、signType、paySign；调用 uni.requestPayment 后再次查询 payStatus。没有支付参数不会模拟成功。
支付回调、金额核验、重复提交和支付幂等处理由后端实现。
